This is the second level in my liminal escape room game. 

You can play it here: https://onyx310.github.io/Escape-Room-Level2-Playable/

In this level, the player will have to count the different color books and use the numbers that they get from that to open the corresponding colored cabinet. In the cabinet there are symbols that will correspond to numbers that the player will be able to find on a piece of paper hidden somewhere within the rooms (I haven't added this sheet yet so the code for the final door is just 1234). 

I wrote all scripts in C# and made all of the 3D assets.
